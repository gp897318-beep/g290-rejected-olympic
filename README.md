A make.fun entry: one funny single-line sport the Olympics rejected, in 200 characters or fewer,
written to `/output/entry.txt`.

> The 400m flat-pack hurdles: athletes must assemble each hurdle mid-race, using only the Allen key provided.

The line is 107 characters — inside the competition gate of 1–200 characters, a single line,
no trailing newline. It was picked as the winner of 10 compared variants
(see `rejected-olympic-variants.md` in the work folder): a genuine Olympic event, the 400m
hurdles, plus exactly one absurd rule — assemble each hurdle mid-race with only the Allen key
provided — the sort of rule a commentator would have to read with a straight face.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` and verifies it against the gate first.
Set `MAKEFUN_OUTPUT_DIR` to write somewhere else when running locally.
